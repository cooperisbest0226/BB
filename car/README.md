# 車輛保養紀錄 PWA

依《車輛保養紀錄 PWA — UI/UX 設計規格書》實作。深色為主場、實拍英雄圖 + 健康環、四宮格分類入口、底部五分頁。

目前版本 **v1.4.0**，支援多台車輛（汽車 + 機車）與加油油耗追蹤。

## 檔案結構

部署時**必須維持這個結構**，`start_url` 是 `./`，所以主檔名一定要是 `index.html`：

```
/
├── index.html              主程式（HTML + CSS + JS 全內嵌）
├── sw.js                   Service Worker（離線快取）
├── manifest.webmanifest    PWA 設定
├── img/
│   ├── hero-car.webp       汽車英雄圖（WebP，主要）
│   ├── hero-car@2x.webp
│   ├── hero-car.jpg        JPEG 後備（舊瀏覽器）
│   ├── hero-car@2x.jpg
│   ├── hero-plate.webp     機車／自建車輛用的光暈底圖
│   ├── hero-plate@2x.webp
│   ├── hero-plate.jpg
│   └── hero-plate@2x.jpg
└── icons/
    ├── icon-192.png
    ├── icon-512.png
    ├── maskable-512.png
    └── apple-touch-icon.png
```

## 上架 GitHub Pages

1. 在 GitHub 建一個新的 repository（public）。
2. 把上面三個檔案 + `img/` 與 `icons/` 兩個資料夾整包上傳到 repo 根目錄。

   ```bash
   git init
   git add .
   git commit -m "第一版：車輛保養紀錄 PWA"
   git branch -M main
   git remote add origin https://github.com/<你的帳號>/<repo 名稱>.git
   git push -u origin main
   ```

3. 進 repo 的 **Settings → Pages**，Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`，按 Save。
4. 等 1–2 分鐘，網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

GitHub Pages 本身就是 HTTPS，Service Worker 與 PWA 安裝都能正常運作。

## 安裝到 iPhone 主畫面

用 **Safari** 開上面的網址 → 分享鈕 → 加入主畫面。之後從主畫面開啟就是全螢幕、無網址列的 standalone 模式，離線也能開。

> 只有 Safari 能安裝 PWA，Chrome/Firefox on iOS 不行。

## 資料存在哪裡

全部存在你手機瀏覽器的 **IndexedDB**（資料庫名 `vehicle_maint_v1`），不會上傳到任何伺服器。

因此要注意：

- 換手機、清除 Safari 資料、或刪除主畫面圖示都可能讓資料消失。
- 「我的 → 匯出備份」會下載一份 JSON，建議定期存到 iCloud 雲碟。
- 「我的 → 匯入備份」可以還原。

## 更新版本

改完 `index.html` 之後，**記得同時把 `sw.js` 裡的 `CACHE` 版本號往上加**（例如 `vehicle-maint-v1.0.1`），否則舊的快取會一直被沿用，使用者看不到新版：

```js
const CACHE = 'vehicle-maint-v1.4.1';
```

App 內建更新偵測：偵測到新版時，畫面頂端會出現藍色橫幅提示「有新版本可用」，按下重新載入即可套用。

## 多車輛

支援任意數量的汽車與機車，每台車有**各自獨立**的紀錄、保養週期、健康度與統計。

- 切換車輛：點首頁車名（旁邊有 › 箭頭），或到「我的 → 我的車庫」
- 新增車輛：車輛切換器下方的「新增一台車」，或「我的 → 新增車輛」
- 車型（汽車／機車）決定套用哪一組預設保養週期，之後仍可逐項調整

**預設保養週期**

| | 汽車 | 機車 |
|---|---|---|
| 機油 | 5,000 km／6 個月 | 1,500 km／3 個月 |
| 機油芯 | 10,000 km／12 個月 | — |
| 齒輪油 | — | 6,000 km／12 個月 |
| 傳動皮帶／普利珠 | — | 15,000 km／24 個月 |
| 空氣濾芯 | 10,000 km／12 個月 | 10,000 km／12 個月 |
| 火星塞 | 40,000 km／48 個月 | 10,000 km／12 個月 |
| 煞車來令片／煞車皮 | 20,000 km／24 個月 | 10,000 km／12 個月 |
| 輪胎（換位／檢查） | 10,000 km／12 個月 | 15,000 km／24 個月 |
| 變速箱油 | 40,000 km／48 個月 | — |
| 冷卻液 | 40,000 km／48 個月 | 20,000 km／24 個月（水冷車） |
| 電瓶 | 36 個月 | 24 個月 |

這些是通用建議值，實際請以原廠手冊為準。

**封面照片**：汽車預設用內建的實拍圖、機車用光暈底圖加線條圖示。想用自己的車照，在車輛表單的「封面照片」上傳即可（會壓到最長邊 1000px）。

## 加油與油耗

新增紀錄時把類型選成「加油」，會多出油量、單價與是否加滿三個欄位（填了油量和單價，金額會自動算）。

**油耗怎麼算**：只有「加滿 → 加滿」的區間能得到準確數字 —— 兩次加滿之間跑的里程 ÷ 這段期間灌進去的總油量。中途沒加滿的紀錄，油量會累加進下一次加滿的區間，所以照實記就好，但**加滿時務必勾「加滿」**，否則那一段會被跳過。

要看到第一個油耗數字，至少需要兩次加滿紀錄。統計頁會顯示平均油耗、最近一次、每公里油錢、累計加油量，以及最近 8 個區間的變化圖與最省／最耗的一次。

> 油耗突然變差通常是胎壓不足、空氣濾芯髒了或火星塞老化的早期徵兆，值得留意。

## 這一版有的功能

- **首頁**：英雄圖、車輛健康度環、四宮格快速入口（保養／維修／加油／保險）、近期提醒
- **時間軸**：依月份分組的完整紀錄，可依保養／維修／加油／保險／其他篩選；點任一筆可直接編輯或刪除；加油紀錄會直接顯示該區間的 km/L
- **統計**：年度／近 12 個月花費長條圖可切換、今年花費、累計花費、平均每公里養車成本、分類佔比、油耗分析
- **我的**：我的車庫（多車輛管理）、更新里程、保養週期設定、深淺色切換、匯出／匯入備份、清除所有資料

健康度是依「保養週期設定」裡各項目的剩餘里程與剩餘天數，取兩者較急迫的一項換算後平均而得；保險到期日也一併納入計算。

除了保養項目，**強制險、第三人責任險、定期排氣檢驗**的到期日也會納入健康度與提醒。

項目比對採**關鍵字模糊比對**（機油／濾芯／輪胎／煞車等），所以紀錄名稱不必跟內建規則完全一樣，像「機油保養＋煞車＋輪胎」這種組合式標題也能正確對應。

## 已知限制

- 提醒是開啟 App 時計算並顯示，不是背景推播（iOS 的 PWA 對推播支援有限）。
